Fase 1: Saberes Previos ABP (Fundamentación Teórica)

1. ¿Por qué una estrategia Offline-First es crítica para entornos industriales y de taller?

En talleres y naves industriales de SENATI, la cobertura móvil o Wi-Fi suele ser inestable debido a maquinaria pesada o bloqueos estructurales. Una arquitectura Offline-First garantiza que el aplicativo nunca se congele ni pierda avances, permitiendo registrar observaciones y entregas localmente con sincronización garantizada al reconectar.

2. ¿Cuál es la función del archivo manifest.webmanifest en la instalación de una app?

Proporciona los metadatos necesarios (nombre corporativo, colores institucionales, modo de visualización standalone e íconos adaptativos) para permitir la instalación de la aplicación en la pantalla de inicio del dispositivo como una app nativa sin requerir tiendas de aplicaciones.

3. ¿Qué diferencia existe entre almacenar recursos en Cache Storage y datos estructurados en IndexedDB?

Cache Storage: Almacena pares Request/Response HTTP (HTML, CSS, JS, fuentes, imágenes y respuestas JSON estáticas de APIs) gestionadas por el Service Worker.
IndexedDB: Base de datos transaccional NoSQL del navegador orientada a documentos/objetos JSON, idónea para encolar transacciones mutables, formularios de entrega y comentarios pendientes.
